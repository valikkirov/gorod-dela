# Клиент (`src/game`, `src/main.ts`)

Отрисовка — Phaser 4, интерфейс — DOM поверх канваса. Клиент читает состояние sim и меняет его только
публичными методами `Simulation`/`City`.

## Запуск (`src/main.ts`)

1. `lang.ts` — первым импортом выбирает язык (`?lang=` → выбор игрока → язык браузера; ВК — всегда русский):
   тексты-константы модулей считаются при загрузке.
2. `initPlatform()` — SDK площадки и облачное сохранение ([save-format.md](save-format.md)).
3. Загрузка сохранения или новый `City`; сезон по календарю (`setHoliday`).
4. Сцены Phaser: `StreetScene` для Кленовой, вторая — для Делового квартала (`window.neighbor`), `sky.ts` — общее небо.
5. `Hud` — панель; связи сцена ↔ панель через `scene.hooks` (`onSelect`, `onPlace`, `sim`) и колбэки панели
   (`onSwitch`, `onShowPlace`, `onLookAt`, `viewDistrict`).
6. Метрика (не на CrazyGames), Telegram Mini App (только сайт), обучение `coach.ts` для нового игрока.

Отладка: `?seed=N` — новый город без сохранения; в консоли `window.city`, `window.scene`, `window.neighbor`.

## Карта (`StreetScene.ts`)

Сетка 40 (сдвиг 20 по x), вид 3/4, двери на фасадах. Слои: земля (`ground.ts`), здания и свет из атласов
(`atlas.ts`, кадры — `atlasFrames.ts`, сгенерированы скриптами), жители и герои (`walkerFrame`), транспорт
(`traffic.ts`, декорация), животные (`animals.ts`), границы района (`borders.ts`), туман (`fog.ts`), погода (`weatherFx.ts`).
Камера: зум, перетаскивание, `reveal(rect)` — показать место, `viewDistrict()` — какой район на экране.
`selectPlace(place, notify)` — рамка вокруг здания; с `notify=false` карточка не открывается (так работает 📍).

## Панель (`hud.ts`)

Один класс, рисует HTML-строки. Группы вкладок точки: Обзор, Меню (меню, склад), Команда, Гости, Развитие
(зал/стойка, вехи, кредит). Плюс общий отчёт «Весь бизнес», карточки жителя и здания, отчёт дня.

- `setHtml(el, html)` — обновляет элемент, только если разметка поменялась (кеш в `WeakMap`): сравнивать
  `innerHTML` нельзя — `&nbsp;` сериализуется иначе, и элемент перерисовывался каждый кадр.
- Тексты — через `L`/`tr`, короткие слова привязаны неразрывным пробелом (`bindShort` в `sim/heroes.ts`).
- Действия — `data-action`/`data-item` на кнопках, один обработчик кликов.
- На телефоне панель — нижний лист (`drawer.ts`: свёрнут / наполовину / почти весь экран).

Отдельные вкладки и окна: `hall.ts` (зал), `stand.ts` (стойка киоска), `eventCard.ts` (события, ставят паузу),
`portraits.ts` (портреты и интерьеры зданий), `icons.ts`, `soundPanel.ts`.

## Обучение

- `coach.ts` — пошаговое обучение в игре (требование модерации ВК, п. 4.2.4): рамка вокруг нужного элемента и
  подсказка рядом, шаг закрывается действием игрока. Шаги: житель → карточка → помещение → меню → цена →
  скорость → первый гость → отчёт дня. Сигналы шагов — `coachSignal()` и клики по `data-action`.
  Пройдено или пропущено — `localStorage['gorod-dela:coach-done']`.
- `tutorial.ts` — пять карточек «Как играть», справка по кнопке внизу панели.
- «Первые шаги» (`sim/firstSteps.ts`) — галочки за первые действия.

## Поделиться и конкурс

- `shareHall.ts` — картинка зала 1080×1350 (рамка Бренда 3.0, логотип, зал как на экране). ВК — история,
  сайт — Web Share с файлом или скачивание и копирование ссылки (`shareLink` с `utm` и `ref`).
- `contest.ts` — конкурс «Новогодний зал» (1–21 декабря, только русский, сайт и ВК): та же картинка с конкурсной
  лентой и хэштегом. `?contest=on|off` — включить для проверки.
- `challenge.ts` — испытание недели: общий seed, своё сохранение.

## Площадки (`platform.ts`)

`PLATFORM` = `web | yandex | vk | crazygames` (из `VITE_PLATFORM`, режим сборки). `IS_PORTAL` — на площадке:
без внешних ссылок, без Boosty, без переноса файлом и испытания. SDK: «загружено», разметка геймплея,
пауза по просьбе площадки, облако (Яндекс, CrazyGames).

## Аккаунт (`account.ts`, `telegram.ts`)

Вход через Telegram: в Mini App — по данным запуска, на сайте — кнопкой (oauth.telegram.org). Облачное
сохранение — на сервере аккаунтов ([build-deploy.md](build-deploy.md)).

## Звук (`sound.ts`)

Фон улицы и музыка по времени суток, звуки событий. По умолчанию выключен; файлы `src/game/sound/*.mp3`.
