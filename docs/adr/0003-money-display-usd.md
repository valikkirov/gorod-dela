# 0003. Деньги в рублях, доллары только на экране

Статус: принято · Дата: 2026-11-23

## Контекст
Английская версия для западных площадок (CrazyGames). Рубли западному игроку непонятны; пересчитывать баланс
под доллары — риск сломать проверенные прогоны.

## Решение
Вся экономика — целые рубли. `formatMoney` в английской версии показывает доллары: сумма ÷50 (`USD_PER_RUB`),
мелкие с центами, крупные без. Шаг цены 10 ₽ = $0.20.

## Последствия
- Баланс один на оба языка, прогоны не повторяем.
- Суммы в текстах — только через `formatMoney`/`money()`; число с «₽» в шаблоне — ошибка.
- Если когда-нибудь понадобится своя экономика для запада — новый ADR.
