# 0002. Ключ перевода — русский текст

Статус: принято · Дата: 2026-11-07

## Контекст
Игра написана по-русски, тексты разбросаны по sim и интерфейсу. Нужна английская версия без переписывания
всех строк на идентификаторы.

## Решение
`L('текст')` и `tr\`шаблон ${x}\`` — ключом служит сам русский текст (шаблон — с `{0}`, `{1}`). Словарь —
`src/i18n/en.ts`, каталог строк собирает `scripts/i18n/scan.mjs`. Язык выбирается до загрузки модулей.

## Последствия
- Русский код читается как есть, перевод не мешает писать.
- Любая правка русской строки или порядка подстановок ломает её перевод — после правок нужен скан и сверка
  (см. [i18n.md](../i18n.md)).
- Переключить язык без перезагрузки нельзя.
