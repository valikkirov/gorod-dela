## Как поддерживать

- Поменял поведение sim — обнови раздел в `simulation.md` и строку в `CHANGELOG.md`.
- Добавил поле в сохранение — `save-format.md`; несовместимо — подними `SAVE_VERSION` и опиши.
- Новая цель Метрики — таблица в `analytics.md`.
- Решение, которое потом захочется оспорить (формат данных, отказ от варианта), — новый ADR в `adr/`
  по шаблону [adr/README.md](adr/README.md). Старые ADR не переписываем: если решение поменялось — новый ADR
  со ссылкой «заменяет NNNN».
- Числа баланса здесь не дублируем: источник правды — константы в коде (`ECONOMY`, `BAKERY`, `PREMISES`…),
  в документации — ссылка на них и смысл.
