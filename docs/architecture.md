# Архитектура

Браузерная игра, mobile-first. TypeScript (strict), Phaser 4, Vite, Vitest. Node 20+.

## Слои

```
┌──────────────────────────── браузер ─────────────────────────────┐
│ src/main.ts — сборка всего вместе: город, сцены, панель, площадка │
│                                                                   │
│ src/game/  отрисовка и интерфейс                                  │
│   StreetScene (Phaser) — карта района, жители, транспорт, погода  │
│   hud.ts (DOM поверх канваса) — панель, карточки, отчёты          │
│   platform.ts, metrika.ts, account.ts — площадки, аналитика, облако│
│        │ читает состояние, меняет только через публичные методы   │
│        ▼                                                          │
│ src/sim/   ядро симуляции — чистый TypeScript, без Phaser и DOM    │
│   City → Simulation (точка игрока в районе) → жители, кафе, склад  │
└───────────────────────────────────────────────────────────────────┘
          │ сохранение (JSON)                    ▲ облако
          ▼                                      │
   localStorage / SDK площадки        server/account (Yandex Cloud Function)
```

Правила слоёв (из `CLAUDE.md`):

- `src/sim/` не импортирует ничего из Phaser, DOM и `src/game/`. Этот код потом переедет на сервер.
- `src/game/` читает состояние sim и меняет его только через публичные методы (`setPrice`, `openCafe`, `chooseEvent`…).
- Тексты интерфейса — в `src/game/`; тексты, которые рождает симуляция (причины, новости, отчёт), — в sim через `L`/`tr`
  (см. [i18n.md](i18n.md)).

## Время

- Игровое время — минуты с начала первого дня (`src/sim/clock.ts`: `hm`, `dayNumber`, `minuteOfDay`).
- Шаг симуляции `STEP = 0.2` игровой минуты (`simulation.ts`). `City.advance(dt)` копит остаток шага в `carry`
  и гоняет все точки в ногу.
- 1 игровой день = 150 реальных секунд при ×1 (≈ 9,6 игровой минуты в секунду). Скорости ×1/×2/×4, пауза,
  «промотать до утра».

## Детерминизм

- Один seed — один и тот же город. Случайность только через `Rng` (mulberry32, `src/sim/rng.ts`);
  `Math.random` и `Date.now` в sim запрещены.
- Характер жителя выводится из seed и номера жителя отдельным генератором — основной поток не сдвигается.
- Календарь игрока (Новый год, конкурс) в sim не попадает: клиент сам говорит sim, какой сезон
  (`setHoliday`, `setHolidayDay`).
- Язык влияет только на тексты и имена, не на поток случайностей (списки имён одной длины, см. [i18n.md](i18n.md)).

## Модель данных с запасом

- У мест есть `territoryId` (улица → район → город).
- Суммы — целые рубли с кодом валюты (`Currency`); в английской версии доллары только на экране.

## Папки

```

src/game/       клиент: сцены, интерфейс, площадки, звук, арт (art/ — атласы WebP)
src/i18n/en.ts  английский словарь
tests/          тесты Vitest
tools/          прогоны баланса (balance.ts, scenarios.ts)
scripts/        сборка графики, i18n-сканер, автопостинг, сертификаты, zip площадок
server/account/ сервер аккаунтов и облачных сохранений (Yandex Cloud Function)
art-src/        исходники графики
social/         очередь автопостинга
docs/           эта документация
```
