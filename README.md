# Город дела

Симулятор предпринимателя в живом городе. Рабочее название.

Игрок начинает обычным жителем улицы, наблюдает, чего не хватает соседям, открывает своё дело и растёт до сети, производства и логистики. Спрос создают сами жители: у каждого свой распорядок, доход и вкусы.

Геймдизайн-документ: https://claude.ai/code/artifact/e5251e4e-7faa-4f67-a81f-42d2c562ce59
ТЗ на графику: https://claude.ai/code/artifact/a775eeb6-3a28-43cc-8281-6d17f3eae58e
Графика (Figma): https://www.figma.com/design/iR0qD6EPxPVMz7Z8ZFWi0j — как обновить в игре: `scripts/README.md`

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev      # локально: http://localhost:5173
npm test         # тесты симуляции
npm run build    # сборка в dist/
```

Отладка: `?seed=7` в адресе — новый город без загрузки сохранения; в консоли браузера доступен `sim`
(например, `sim.advance(120)` — промотать 2 игровых часа).

Управление: пробел — пауза, клавиши 1/2/3 — скорость ×1/×2/×4, клик по жителю — его карточка.

## Структура

```
src/
  sim/     ядро симуляции: время, карта, жители, распорядок. Чистый TypeScript без движка —
           на этапе 2 этот код переедет на сервер без переписывания
  game/    отрисовка (Phaser) и интерфейс (DOM)
tests/     тесты симуляции (Vitest)
```

## Этап 0 — прототип

- [x] Улица: 100 жителей, 40 пассажиров метро, 36 гостей района с распорядком дня, игровые часы и скорость; ночная жизнь: молодёжь и ночная смена
- [x] Карточка жителя: кто он, где живёт и работает, расписание, готовность платить
- [x] Кафе игрока: открытие, своё меню из каталога (до 8 позиций), бар, часы через полночь и круглосуточно, бариста, очередь
- [x] Решение жителя: цена, крюк, любимая позиция, лояльность — и честная причина отказа
- [x] Экономика: капитал, аренда, коммуналка, бариста на смену (2 500 ₽ до 12 ч) или почасово (300 ₽/ч), ночью +20 %, налог 6 %, банкротство
- [x] Отчёт дня: доходы и расходы, кто не зашёл и почему, прогноз на завтра
- [x] Дни недели (будни и выходные) и погода с прогнозом
- [x] Склад: ингредиенты со сроками, доставка в 6:00, опт, списание, автозаказ на будни и выходные
- [x] Маркетинг: «знают о кафе», вывеска, листовки, соцсети, сарафан, счастливые часы, карта лояльности
- [x] Сохранение прогресса в браузере (автосохранение) и «Начать заново»
- [x] Графика: вид 3/4, сетка 40, спрайты жителей с анимацией шага, здания с дверями на фасадах, ночной свет в окнах
- [x] Автодеплой в Yandex Object Storage
- [x] Отчёт дня: сравнение с похожим днём, главный фактор, потери по часам и типам жителей, наблюдения, история изменений
- [x] Предупреждение, когда касса на исходе; обучение на 30 секунд; кнопка «Предложить идею»
- [x] График бариста по дням недели и часам, разовый вызов на сегодня, «промотать до утра»
- [x] Два помещения: киоск у метро и кафе с залом; поток пассажиров и гостей района; дозаказы; плюс за понятный формат
- [x] Пакетный прогон форматов: `npx tsx tools/balance.ts`
- [ ] Качество и атмосфера (интерьер), отзывы
- [x] Конкурент-NPC: открывается в соседнем помещении через 4 дня, фиксированная стратегия, акция каждую третью неделю
- [x] Знакомые лица: 6 жителей с чертой и историей визитов, статус (постоянный / заходит / пропал и почему), новости в отчёте, ★ на карте
- [x] Вехи первой точки (7 штук) и улучшения, которые они открывают: вторая кофемашина, холодильная витрина, уютный интерьер. Вехи в прогоне баланса: `npx tsx tools/balance.ts 28 4 --milestones`
- [x] События-дилеммы: поломка кофемашины, праздник в сквере, распродажа у поставщика, заказ офиса, блогер, отгул бариста. Карточка с ценой каждого варианта, не решил до конца дня — вариант по умолчанию
