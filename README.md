# Город дела

Симулятор предпринимателя в живом городе. Рабочее название.

Игрок начинает обычным жителем улицы, наблюдает, чего не хватает соседям, открывает своё дело и растёт до сети, производства и логистики. Спрос создают сами жители: у каждого свой распорядок, доход и вкусы.

Геймдизайн-документ: https://claude.ai/code/artifact/e5251e4e-7faa-4f67-a81f-42d2c562ce59

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev      # локально: http://localhost:5173
npm test         # тесты симуляции
npm run build    # сборка в dist/
```

Отладка: `?seed=7` в адресе — другой город; в консоли браузера доступен `sim`
(например, `sim.advance(120)` — промотать 2 игровых часа).

Управление: пробел — пауза, клавиши 1/2/3 — скорость ×1/×2/×4, клик по жителю — его карточка.

## Структура

```
src/
  sim/     ядро симуляции: время, карта, жители, распорядок. Чистый TypeScript без движка —
           на этапе 2 этот код переедет на сервер без переписывания
  game/    отрисовка (Phaser) и интерфейс (DOM)
tests/     тесты симуляции (Vitest)
```
