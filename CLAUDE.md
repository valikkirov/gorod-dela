# Город дела — правила проекта

Браузерный экономический симулятор (mobile-first). Команда из двух: Валентин — геймдизайн и арт, Claude — код.
GDD: https://claude.ai/code/artifact/e5251e4e-7faa-4f67-a81f-42d2c562ce59 — источник правды по механикам.

## Стек
TypeScript (strict), Phaser 4, Vite, Vitest. Node 20+.
Команды: `npm run dev`, `npm test`, `npm run build` (tsc + vite).

## Архитектура
- `src/sim/` — ядро симуляции. **Никаких импортов из Phaser, DOM или `src/game/`.** Детерминировано
  при одном seed (только `Rng`, никакого `Math.random` и `Date.now`). Этот код потом переедет на сервер.
- `src/game/` — отрисовка (Phaser) и интерфейс (DOM поверх канваса). Читает состояние sim, не меняет его
  в обход публичных методов.
- Время: игровые минуты с начала первого дня. 1 игровой день = 150 реальных секунд при ×1.
- Модель данных с запасом из GDD: у мест есть `territoryId`; суммы денег будут храниться с кодом валюты.

## Правила
- Каждый новый слой механик — только когда предыдущий стал интересным (главный риск — «игра обо всём»).
- Новая логика sim покрывается тестом в `tests/`.
- Интерфейс проектируется под вертикальный экран телефона.
- Тексты интерфейса — на русском. Короткие предлоги, союзы и частицы привязываются к следующему слову
  неразрывным пробелом (` `), тире не начинает строку.
- Сохранение: `Simulation.serialize/restore`. Добавил новое состояние в sim — добавь его в сохранение.
  Если старые сохранения становятся несовместимы — увеличь `SAVE_VERSION`.
- Сборка с `base: './'` — открывается из любой папки и из бакета Object Storage.
