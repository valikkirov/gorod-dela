# Автопостинг

Очередь постов для Telegram и ВКонтакте. Публикует задача GitHub «Автопостинг» (`.github/workflows/social.yml`)
каждый день в 10:12 по Москве: всё, у чего дата сегодня или раньше и что ещё не вышло. Что вышло — `published.json`.

- Пост — файл `queue/<ГГГГ-ММ-ДД>-<имя>.md` (формат — в начале `scripts/social/publish.mjs`, пример — `queue/_пример.md`).
  Файлы, которые начинаются с `_`, не публикуются.
- Картинки — в `img/`, в посте: `images: имя.jpg, другое.jpg`.
- Куда публиковать — `config.json`: id группы и тем Telegram, короткое имя группы ВК.
- Ключи — только в секретах репозитория: `TG_BOT_TOKEN`, `VK_TOKEN`.

Запуск вручную: Actions → «Автопостинг» → Run workflow → режим (`dry-run` — посмотреть, что выйдет; `check` — проверить
ключи; `chats` — узнать id группы и тем; `test-tg` — пробное сообщение; `publish` — опубликовать).
